# دليل تشغيل ونشر منظومة إدارة العملاء والمبيعات CRM
## النسخة الإنتاجية الرسمية الجاهزة للنشر (Production Release v1.0.0)

---

### 🌟 نبذة عن النظام:
منظومة CRM متكاملة لإدارة العملاء والمبيعات وفريق العمل، تشمل:
1. **بوابة الإدارة المركزية للأونر (`/crm`)**: لمتابعة مؤشرات الشركة العامة والأقسام.
2. **قسم المبيعات وتوزيع العملاء (`/sales`)**: إسناد يدوي، جماعي، وبالتساوي التلقائي (Round-Robin).
3. **قسم إدارة المستخدمين وحسابات السيلز (`/users`)**: إنشاء وتعديل وحذف حسابات السيلز وصلاحياتهم.
4. **سجل العمليات والرقابة التفصيلي (`/logs`)**: توثيق فوري لكل عملية تحدث في النظام.
5. **بوابة السيلز المستقلة (`/sales-portal`)**: لوحة مخصصة لكل موظف مبيعات معزولة تماماً عن صفحات الإدارة.
6. **شات فريق العمل المدمج (WhatsApp Chat Widget)**: محادثات جماعية وخاصة بين الأونر وأعضاء الفريق.

---

### 📋 متطلبات التشغيل الأساسية:
1. **Node.js**: الإصدار 18 فما فوق (LTS موصى به).
2. **قاعدة بيانات PostgreSQL**: الإصدار 14 فما فوق مع قاعدة بيانات باسم `crm`.

---

### ⚡ خطوات التشغيل السريعة:

#### على بيئة ويندوز (Windows):
1. تأكد من أن خدمة PostgreSQL تعمل.
2. انقر نقراً مزدوجاً على ملف:
   ```cmd
   start_production.bat
   ```
   *سيقوم الملف تلقائياً بفحص المكتبات وتثبيتها، ثم تشغيل السيرفر وفتح المتصفح على رابط النظام.*

#### على بيئة لينكس / سيرفر سحابي (Linux / VPS):
```bash
# 1. إعطاء تصريح التشغيل للملف
chmod +x start_production.sh

# 2. تشغيل السكربت
./start_production.sh
```

### 🛡️ حماية الصلاحيات (RBAC Security):
* **نقطة الدخول موحدة**: كلاً من الأونر والسيلز يسجلون الدخول من نفس الصفحة الرئيسية (`/`).
* **حارس الأمان (`pageGuard`)**: يمنع موظفي السيلز منعاً باتاً من فتح أي صفحة إدارية (`/crm`, `/sales`, `/users`, `/logs`) ويحولهم فوراً إلى `/sales-portal`.
